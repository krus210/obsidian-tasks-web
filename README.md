# Задачи в браузере

Локальная веб-страница для хранилища Obsidian: все задачи видны деревом «папка → заметка →
задача», есть фильтры по датам и матрица Эйзенхауэра, задачи добавляются в одно поле.
Отдельной базы нет: приложение читает и правит те же Markdown-заметки в формате плагина
[Tasks](https://github.com/obsidian-tasks-group/obsidian-tasks) (`🔺 ⏫ 🔼 🔽 ⏬`, `➕ ⏳ 📅 ✅`),
поэтому Obsidian, запросы Tasks и Obsidian Sync работают как раньше.

Интерфейс на русском.

## Запуск

Нужен Node.js 22 или новее, зависимостей нет.

```fish
git clone https://github.com/krus210/obsidian-tasks-web.git
cd obsidian-tasks-web
cp config.example.json config.json   # укажи путь к хранилищу в "vault"
npm start
```

Открой http://localhost:7373. Сервер слушает только `127.0.0.1`.

## Что делает

- **Фильтры «Когда»**: сегодня (вместе с просроченным), просрочено, завтра, эта и следующая
  неделя, без даты, все открытые, все задачи (без фильтров, вместе с выполненными и архивом)
  и архив. Дата «попадает», если на неё приходится ⏳, 📅 или 🛫, как у `happens` в Tasks.
- **Матрица**: квадрант задаёт эмодзи приоритета: 🔺 Q1, ⏫ Q2, 🔼 Q3, ⏬ Q4, 🔽 «Когда-нибудь»;
  без приоритета задача попадает в «Разобрать». Перетаскивание карточки меняет эмодзи в заметке.
  Названия квадрантов задаются в начале `public/app.js` (`QUADRANTS`).
- **Где**: счётчик папки — все её открытые задачи. Клик по папке или по названию заметки
  показывает их целиком, без фильтра по дате и квадранту; сузить можно после. Счётчики
  «Когда» и «Матрица» считаются внутри выбранной папки.
- **Быстрый ввод** с подсказками, как в Tasks: `!` — квадрант, `@` — дата (⏳ план или
  📅 срок, например `@пт`, `@31.10`), `#` — заметка или её раздел. Выбор стрелками и Enter.
  Задача идёт в заметку из поля «в» рядом с кнопкой: по умолчанию в `inbox` из настроек,
  а если открыта конкретная заметка — в неё. Новая задача и подзадача получают `➕`
  с текущей датой; в редакторе она видна как «Создана».
- **Названия ссылок**: вставленная ссылка заменяется на `[Название](ссылка)`, как у плагина
  Auto Link Title; текст названия можно поправить до сохранения. Для YouTube и X название
  берётся из их oEmbed. В редакторе кнопка «Названия для ссылок» делает то же для уже
  сохранённой задачи. Страницы, которые требуют входа, остаются ссылками.
- **Перенос**: в редакторе поле «Заметка»; перетаскиванием — на заголовок заметки, раздел,
  другую задачу (встанет сразу после неё на её уровне) или на заметку в боковой панели,
  которая раскрывается во время перетаскивания. Подзадачи переезжают вместе с задачей.
- **В календарь**: кнопка 📆 у задачи — выбираешь день, время и длительность, и открывается
  Google Календарь с готовым событием: название задачи, ссылки из неё и ссылка на заметку
  в Obsidian. Событие сохраняешь сам кнопкой «Сохранить»; занятость дня видна там же,
  во вкладке «Найти время». Заметка при этом не меняется.
- **День в календарь**: в разделах «Сегодня» и «Завтра» кнопка «📆 В календарь на завтра: N»
  открывает список показанных задач. Каждой ставишь время и длительность или снимаешь
  галочку; задача без времени станет событием на весь день. Кнопка скачивает один файл
  `.ics` и открывает импорт Google Календаря — выбери файл и нажми «Импорт». Google API
  и настройка не нужны; на macOS файл можно открыть и в Календаре.
- **Выполнение и архив**: галочка у задачи ставит `[x]` и `✅` и переносит её вместе
  с подзадачами в конец раздела `## ARCHIVE` той же заметки (раздел создаётся, если его нет);
  открытые подзадачи закрываются вместе с ней. Подзадача отмечается на месте, внутри своей
  задачи. У повторяющихся задач (`🔁 every week on Monday` и подобных) следующая копия
  остаётся на месте, как в Tasks.
- **Архив**: раздел «Архив» в боковой панели показывает закрытые задачи, последние сверху.
  «Вернуть» или снятая галочка открывает задачу и ставит её к открытым задачам заметки;
  подзадачи, закрытые в тот же день, открываются вместе с ней. Если над архивом остались
  задачи, отмеченные в Obsidian, кнопка «Перенести в архив» уберёт их все разом.
- **Отмена**: в уведомлении после каждого действия; перенос откатывается в обеих заметках.
- **Живое обновление**: правки из Obsidian появляются на странице сами. После перезапуска
  сервера вкладка переподключается за 2–3 секунды, а если обновился интерфейс —
  перезагружается сама, но не посреди правки или набора задачи.

Клавиши: `N` — новая задача, `/` — поиск, `Esc` — закрыть редактор.

## Безопасность

Заметки:

- Файлы меняются только по нажатию в интерфейсе. Перед записью сервер перечитывает
  заметку и сверяет строку задачи; если её изменили в Obsidian, правка отклоняется.
- Отмена срабатывает, только если заметку после действия больше никто не менял.
- Правится только строка задачи (при архивации, возврате и переносе — её блок); порядок полей
  совпадает с тем, что пишет Tasks. Писать можно только в `.md` внутри хранилища,
  кроме скрытых и исключённых папок.

Сеть:

- Сервер слушает только `127.0.0.1` и отвечает только на `Host` `localhost` и `127.0.0.1`,
  поэтому чужие сайты не достучатся до него через DNS rebinding. Изменения принимаются
  только как JSON с того же `Origin`.
- Страница отдаётся с Content-Security-Policy: скрипты только свои, встраивать страницу
  в чужие сайты нельзя. Ссылками в задачах становятся только `http`, `https`, `mailto`
  и `obsidian`.
- Наружу сервер ходит только за названиями ссылок. Перед запросом и на каждой
  переадресации он проверяет, что адрес сайта не ведёт на этот компьютер или
  во внутреннюю сеть.
- Страница загружает шрифт Onest с Google Fonts.

## Настройка

`config.json` (без него берётся `config.example.json`):

- `vault` — путь к хранилищу, абсолютный или относительно этой папки;
- `inbox` — заметка для новых задач, путь внутри хранилища;
- `exclude` — папки, где чекбоксы не считаются задачами (например, чек-листы или шаблоны);
- `archiveFolders` — папки, задачи из которых считаются архивными;
- `port` — порт.

Переменные `VAULT` и `PORT` переопределяют конфиг, например для проверки на копии хранилища.

## Ограничения

- Повторы: `every [N] day/week/month/year`, `on <дни недели>`, `on the Nth`, `every weekday`,
  `when done`. Задачу с другим правилом или с `🏁 delete` приложение не отметит и попросит
  сделать это в Obsidian.
- Задачи внутри блоков кода и в исключённых папках не показываются.
